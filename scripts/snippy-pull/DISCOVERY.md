# YouTube-first daily discovery

The source workflow is `tallchap/FlatCreepyInformation/scripts/snippy-pull`.
Run the real Snippysaurus Home snapshot first, retaining its identity check,
100 full videos in original feed order, no Shorts/ads, enrichment and sheet tab.
Search results never stand in for a genuine Home snapshot.

`refined-pull.py` extends the existing YouTube, Brave and TwitterAPI actuators.
It keeps the YouTube long-video duration filter, adds named-speaker searches,
an archive pass without a recency cutoff, and web searches aimed at original
publishers. Twitter is supporting discovery: Top/Latest cursor pagination,
daily refinements for saturated windows, retries, a shared rate limit,
URL/video extraction, duplicate removal and explicit relevance triage.

```
python refined-pull.py --platform youtube-web --output /private/run/youtube-web.json
python refined-pull.py --platform twitter --max-pages 4 --output /private/run/twitter.json
```

The default edition is today's UTC date; `--edition YYYY-MM-DD` reproduces a
historical window. Credentials come only from `YOUTUBE_API_KEY`,
`BRAVE_API_KEY`, and `TWITTERAPI_KEY`. Keep raw responses outside the public
site directory. `discovery-plan.json` records seed queries and editorial rules.

Do not rank by raw counts. Verify the speaker and original interview; follow
the poster's own source link and check the actual timed transcript. Text-only
posts, plausible web matches and unreviewed native videos stay in a review
queue. Detect an original-source match by its video ID; similar titles or
clip durations are insufficient. Reject unrelated uses of “loss of control”.

The top five directly concern catastrophic risk, alignment/control, dangerous
capabilities or safety governance. Recency is a strong preference, not a
cutoff. Wes Roth, Riley Brown, Matthew Barnett and Rowan Cheung are held by
default; only verified original interviews can qualify. Keep qualifications
and attribution in the clip and hook. No Shorts.

Report requests, returned and unique items, capped versus exhausted queries,
errors, rejected/held leads, transcript provenance and usage. Count duplicates
and the Twitter per-call minimum in price estimates. Include failed attempts,
distinguish reported usage from list-price estimates, and mark missing billing
as unknown rather than zero. Inspect the latest Grabien newsletter separately;
headlines are leads, not verified video transcripts.

The report is generated by `build_debug_page.py` into
`dist/tests/first-pull/`. It is an orphan route. Do not add links to it elsewhere
in the site. Preserve the public deep URL when publishing an updated report.
